# Madrasah Management System (MMS) - Feature Documentation

## 1. Student Management Module (SMS)

### Existing Core Features

- **Result & Performance:**
  - View individual semester/annual exam results.
  - Peer comparison (Compare results with class batchmates/friends for academic performance analytics).
- **Academic Materials & Notices:**
  - Access & download study materials, lecture notes, and class slides.
  - Real-time notice board alerts (Exams, holidays, events).
- **Finance & Fees:**
  - Real-time billing summary (Dues, paid fees, extra charges).
  - Online fee payment integration (bKash, Nagad, Cards).
  - Payment receipt generation and PDF download.
- **Examination Access:**
  - Automated Admit Card generation & print capability (Enabled only when tuition dues = 0).

### Recommended Additional Features

- **Digital Student ID:** Auto-generated ID card with dynamic QR code verification.
- **Course & Subject Enrollment:** Self-service subject/course selection per academic session.
- **Attendance History:** Daily attendance logs, subject-wise attendance percentage, and shortage alerts.
- **Exam Routine & Seat Planning:** Dynamic exam timetable and hall seat allotment status.
- **Leave Application Management:** Digital leave request submission with approval tracking by class teacher.
- **Library Desk:** Track borrowed books, due dates, and pending fines.
- **Digital Complaints & Support:** Confidential feedback/support request submission to authority.
